# Registro de Decisões de Arquitetura (ADRs)

Cada decisão relevante é registrada em `ADR-NNNN-titulo.md`, com Contexto, Alternativas, Decisão e
Consequências. Uma ADR **Proposta** ainda não é decisão: só passa a **Aceita** com confirmação
explícita da equipe. Uma ADR aceita não é editada em seu mérito; se a decisão mudar, uma nova ADR
a substitui.
